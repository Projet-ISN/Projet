# Instructions  
1. Clonez le projet depuis la branche "main" sur [GitHub](https://github.com/Projet-ISN/Projet).  
2. Exécutez `pip install -r requirements.txt` dans le terminal, dans le répertoire où le projet a été cloné.  
3. Créez un fichier `.env` contenant les informations de connexion à la base de données.  
4. Lancez le fichier `main.py`.
